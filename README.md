# 💗 Открытка «Для моей любимой принцессы»

Интерактивная открытка-домик: настоящая 3D-сцена на **Three.js** (крутится, зумится, кликабельна), 5 «этажей» контента (письмо, история, причины любви, воспоминания, мечта), загрузка своих фото и музыки в **локальную базу данных браузера (IndexedDB)**, анимации. Один файл — работает без сервера и бэкенда (кроме CDN для Three.js).

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `for-my-princess`).
2. Загрузи туда файлы `index.html` и `manifest.json` (**Add file → Upload files**).
3. **Settings → Pages** → в **Source** выбери ветку `main`, папку `/root`, **Save**.
4. Через 1–2 минуты сайт появится по адресу вида:
   `https://твой-логин.github.io/for-my-princess/`
5. Отправь ссылку — открывается в браузере на телефоне. Нужен интернет при первой загрузке (Three.js подгружается с CDN); дальше браузер его кэширует.

## 3D-домик

Домик — это настоящая 3D-модель (Three.js): пастельные стены, розовая крыша, светящееся сердце на коньке, фонарь во дворе, кусты цветов. Домик можно **крутить пальцем/мышью** — он и сам медленно вращается. Окна поэтапно зажигаются при загрузке и мягко мерцают. Клик по этажу или по двери открывает соответствующую страницу открытки на весь экран.

## Как редактировать текст и фото

Редактируется **прямо в браузере**, без программирования:

1. Открой сайт.
2. Нажми кнопку **«✎»** в правом верхнем углу — включится редактирование.
3. Кликни по любому тексту (заголовок, письмо, история, причины любви, мечта) и впиши свой текст. Нажми **«✎»** ещё раз, чтобы выключить.
4. Фото — заходишь на нужный этаж (клик по домику) и нажимаешь на рамку с «+»: на «Наша история» и «Воспоминания».
5. Музыка: «Включить музыку» → выбери mp3-файл.

## Локальная база данных (IndexedDB)

Фото и музыка сохраняются не в куки и не в localStorage, а в **IndexedDB** — встроенной базе данных браузера, рассчитанной как раз на файлы и изображения (лимит на порядки больше, чем у localStorage). Всё хранится **локально, в том браузере**, где загружено:

- Текст (письмо, причины любви и т.д.) — в `localStorage`.
- Фото и аудио — в `IndexedDB` (база `dollhouseDB`, хранилище `files`), как настоящие файлы (Blob), без раздувания через base64.

Если хочешь, чтобы получатель сразу увидел твои фото и текст (без того, чтобы он сам что-то загружал):

- заполни открытку у себя в браузере — этого достаточно, если открываешь её на устройстве получателя лично;
- либо для полностью «зашитой» версии впиши текст прямо в `index.html` (ищи `contenteditable="false">текст<`), а фото положи в папку `photos/` репозитория и замени ячейки `data-photo="..."` на `<img src="photos/1.jpg">` — так они будут видны любому, кто откроет ссылку, без загрузки вручную.

## Важно

- Не загружай слишком большие фото/аудио (лучше до 3–5 МБ на файл) — иначе сцена будет дольше грузиться.
- Домику для отрисовки нужен WebGL (есть во всех современных браузерах на телефоне и компьютере).
