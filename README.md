# 💗 Открытка «Для моей любимой принцессы»

Интерактивная открытка-домик: 5 «этажей» (письмо, история, причины любви, воспоминания, мечта), загрузка своих фото, своя музыка, анимации сердечек. Один файл — работает без сервера и бэкенда.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `for-my-princess`).
2. Загрузи туда файлы `index.html` и `manifest.json` (просто перетащи их в репозиторий через веб-интерфейс GitHub — кнопка **Add file → Upload files**).
3. Зайди в **Settings → Pages**.
4. В разделе **Source** выбери ветку `main` и папку `/root`, нажми **Save**.
5. Через 1–2 минуты сайт появится по адресу вида:
   `https://твой-логин.github.io/for-my-princess/`
6. Отправь эту ссылку человеку — она открывается прямо в браузере на телефоне.

## Как редактировать текст и фото

Открытка редактируется **прямо в браузере**, без программирования:

1. Открой сайт (можно у себя на компьютере или уже на GitHub Pages).
2. Нажми кнопку **«✎ Режим редактирования»** в правом верхнем углу.
3. Кликни по любому тексту (заголовок, письмо, история, причины любви, мечта) и просто впиши свой текст.
4. Нажми **«Готово ✓»**, чтобы выключить редактирование (это не обязательно, но убережёт текст от случайных правок при обычных кликах).
5. Фото добавляются в любом режиме — просто нажми на пустую рамку с «+» на этаже «Наша история» или «Воспоминания» и выбери фото с телефона/компьютера.
6. Музыка: нажми «Включить музыку» → выбери свой mp3-файл. Он запомнится и будет играть при следующих открытиях в этом браузере.

Все изменения сохраняются в `localStorage` — то есть **в том браузере**, где ты их внёс. Если хочешь, чтобы открытка сразу открывалась с готовым текстом и фото у получателя (без того, чтобы он сам что-то редактировал):

- Заполни и настрой открытку у себя,
- либо впиши финальный текст сразу в `index.html` (ищи там строки вида `contenteditable="false">Твой текст здесь<`),
- для фото — самый надёжный способ: залей свои фото в репозиторий (папку `photos/`) и замени в коде `data-photo="..."` ячейки на `<img src="photos/1.jpg">`.

## Важно про фото и музыку

- Фото и музыка, загруженные через кнопки на сайте, хранятся локально в браузере (в виде base64) — они не отправляются никуда и не видны другим людям, пока получатель сам не откроет ссылку в своём браузере и не увидит **исходную** версию (без твоих локальных правок, если ты не зашил их в код заранее).
- Поэтому если хочешь, чтобы получатель увидел именно твои фото — лучше зашить их прямо в `index.html` перед публикацией (см. пункт выше), а не полагаться на localStorage.
- Не загружай слишком большие фото/аудио (лучше до 2–3 МБ на файл) — иначе сайт будет долго загружаться.

## Структура файлов

```
index.html     — вся открытка (HTML + CSS + JS в одном файле)
manifest.json  — для «Добавить на главный экран» на телефоне
```
